## Decisions made

- **Odds via screenshot paste, not API** — every major bookmaker site (Oddschecker, Betfair, William Hill) is Cloudflare-protected or JS-rendered; The Odds API has no cycling catalog; Anthropic web_search hits 30k token/min rate limit. Screenshot + vision model is the clean, reliable path.
- **`claude-haiku-4-5-20251001` for vision** — fast and cheap; handles Oddschecker table layout well
- **Average across bookmaker columns** — prompt instructs model to average all visible decimal odds, giving a more stable implied probability than best-odds only
- **`populateOddsTable()` extracted** — shared by both the paste handler and any future programmatic odds loading
