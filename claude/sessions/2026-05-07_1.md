## What was built

- **Dashboard works as file:// with no server** — `build_dashboard.py` injects `window.RIDERS_DATA` and `window.STAGES_DATA` as inline JS between HTML comment markers; `claude.html` reads these directly, no fetch needed
- **fetch_riders.py verified live** — runs clean against Holdet.dk API, writes `shared/data/snapshots/stage_1_holdet.json` with 184 active riders; paths updated to `giro_2026/` subfolder structure
- **184-rider lock** — two-mode filtering: initial run filters to active riders (not eliminated, not DNS); subsequent runs preserve the locked set regardless of mid-race withdrawals
- **One-click refresh** — `claude/engine/refresh.sh` (fetch → build → open); `claude/tools/holdet-refresh.sh` (fetch + build only); `HoldetRefresh.app` AppleScript app registered for `holdet://` URL scheme
- **holdet:// URL scheme** — `on open location` handler in AppleScript; registered with `lsregister`; dashboard Refresh button calls `holdet://refresh` instead of `window.location.href` (which Safari blocked)
- **Column sorting** — all rider table columns sortable; `COLS`, `getSortVal()`, `setSort()`, `renderTableHeader()` pattern
- **All 21 stages in carousel** — previous stub only showed a subset
- **TYPE_FIT tier logic** — matrix of type × stage-type → score ≥ 0.36 = Tier A; replaces terrain_affinity formula that was unreliable
- **Slider auto-balance** — stage-type sliders (flat/hilly/mountain/ITT) auto-sum to 100% via proportional redistribution on each change
- **Stage-relevance odds table** — top-30 riders ranked by `riderStageScore()` (type fit × current stage weights); not by price
- **Stage images via GitHub raw URL** — `https://raw.githubusercontent.com/lstol/holdet-v3/main/shared/data/stage_images/giro_2026/stage-${n}.jpg`; bypasses all file:// limitations
- **Inline server error display** — `#server-msg` div with Copy button instead of `alert()`

## Decisions made

- **Embed data, don't fetch** — `build_dashboard.py` injection pattern chosen over server-side serving; dashboard works standalone without any running process; server.py kept for future optimizer use
- **GitHub raw URL for images** — avoids file:// CORS, avoids needing a local server, works in Safari; requires images be committed to GitHub (they are)
- **holdet:// URL scheme over file:// app launch** — Safari blocks `window.location.href` to file:// paths; custom URL scheme is the correct macOS pattern
- **184-rider lock is permanent** — the 184 active riders at race start are the universe for all 21 stages; mid-race DNS/withdrawals do not remove riders from the set
