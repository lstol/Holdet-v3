The handoff allowed ±0.5% RNG slack; the actual gap is 0.7–2.1%. The
overshoot is consistent with the simulator's unseeded global RNG drift
(scheduled for fix in S16-3): when the search-path heuristic reorders
candidates, the global RNG state is in a different position when the
final team is finally simulated, so even an "unchanged team" sees its
non-depth components shift by RNG noise. No other code change explains
the gap; deferring deeper investigation until S16-3 lands.
