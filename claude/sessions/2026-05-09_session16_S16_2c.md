# Session 16 — Task 2c: Replace Fetch Ingemann with image paste

## TL;DR

Replaced the broken Feltet scraper for Ingemann with a source-agnostic
image-paste workflow. User pastes a screenshot of any expert team
view (Holdet's "view team", a tweet, etc.); a vision call extracts
8 riders + captain; name-matcher resolves abbreviated names ("J. Milan"
→ "Jonathan Milan"); same `stage_N_ingemann.json` schema is written so
downstream `/score-ingemann` consumes it without changes.

## New endpoint

[server.py:88-117](claude/engine/server.py:88) — module-level
`match_rider_name(query, roster)` lifted from inside `score_ingemann`.
Same logic as before (exact → initial+lastname → lastname-only),
now reusable.

[server.py:923-1037](claude/engine/server.py:923) —
`POST /paste-expert-team`

Request: `{stage, image (base64), media_type}`
Response on success:
```json
{
  "status": "ok",
  "riders": [{"name": "<resolved>", "raw_name": "<as shown>", "price_kr": <int>}, ... ×8],
  "captain": "<resolved>",
  "captain_raw": "<as shown>",
  "warnings": ["Unmatched rider: ...", ...]
}
```

Error paths return `{status: "error", message: "..."}` with codes:
- 400: vision returned `{error: ...}`, ≠8 riders, no captain, missing image
- 500: no JSON in vision response, JSON parse failure, unhandled exception

## Vision prompt (full text, for tuning later)

```
You are extracting a fantasy cycling team from a screenshot.

Return ONLY valid JSON in this exact format:
{
  "riders": [
    {"name": "<rider name as shown>", "price_kr": <integer kroner>},
    ... 8 entries total
  ],
  "captain": "<name of the rider with the gold star icon>"
}

Rules:
- Extract exactly 8 riders.
- Names: copy them as shown in the image. Do not expand initials.
  (e.g. "J. Milan" stays "J. Milan", "Paul Magnier" stays "Paul Magnier".)
- Prices: convert European format like "9.575.000" to integer 9575000.
  Ignore any price-change deltas like "+575.000" — those are not the price.
- Captain: the rider with a gold/yellow STAR icon next to their price.
  The green "+" square icon is NOT the captain marker — it appears
  next to multiple riders.
- Ignore non-rider visual elements like sponsor logos (e.g. MERIDA).
- If you cannot identify exactly 8 riders or cannot identify a captain,
  return {"error": "<reason>"} instead.
- No prose, no markdown fences, no explanation. JSON only.
```

Model: `claude-haiku-4-5-20251001` (same as `/parse-odds-image`).

## Side fix: captain resolution in `/score-ingemann`

[optimizer.py:1074](claude/engine/optimizer.py:1074) does an exact-name
match for the captain (`r['name'] == captain_name`). When the image
yields `"A. Vendrame"`, exact match fails and `capt_ti` silently
defaults to position 0 — wrong rider becomes captain in the simulation.

Fixed by resolving captain through `match_rider_name` in `score_ingemann`
([server.py:1057-1061](claude/engine/server.py:1057)) before passing to
`simulate_stage`. Snapshot itself already stores resolved names from the
new endpoint, so this is a defense-in-depth fix that also helps the old
scraper path if Feltet ever resumes.
