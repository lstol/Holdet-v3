## Decisions made

- **Four strategies always returned** (no deduplication or sorting by EV) — preserves each strategy's distinct recommendation.
- **Transfer cost = 1% of buy price per transfer, no cap** — sprint→mountain can be up to 8 transfers.
- **Lookahead formula**: subtract `cost_n1 + 0.7 * cost_n2` from EV — discounted because n+2 is estimated via forward fast-optimize.
- **GC penalty**: sprinters in mountain stages (gc slider >50%) get 50k implicit cost via `build_forward_probabilities()`.
- **`stage_N_results.json` populated manually** (or by future fetch endpoint) — `/stage-results` returns `{found:false}` if absent. Post-stage data fetch is a future task.
